# Soluciones de ejercicios de código

Cada carpeta contiene un programa ejecutable con las soluciones del ejemplo resuelto y las actividades de código de las sesiones 4, 6 y 7 del nivel correspondiente. `Nivel_11` también incluye el reto final integrador. Se omitieron teoría, XP y evaluación.

Ejecuta cada nivel con Java 25 o posterior:

```text
java Nivel_01/Nivel01.java
java Nivel_02/Nivel02.java
java Nivel_03/Nivel03.java
java Nivel_04/Nivel04.java
java Nivel_05/Nivel05.java
java Nivel_06/Nivel06.java
java Nivel_07/Nivel07.java
java Nivel_08/Nivel08.java
java Nivel_09/Nivel09.java
java Nivel_10/Nivel10.java
java Nivel_11/Nivel11.java
```

Los programas ejecutan las actividades de forma secuencial. Para abrir el menú interactivo de reservas del nivel 9, usa `java Nivel_09/Nivel09.java --menu`; para el menú persistente del nivel 11, usa `java Nivel_11/Nivel11.java --menu`. Este último guarda `reservas.bin` y exporta `reservas.csv` en el directorio desde donde se ejecuta.
